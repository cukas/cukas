## What I'm building now

**[KERNlang/agon](https://github.com/KERNlang/agon)** is here — and it does everything the old projects did, plus a lot more.

These projects are **no longer supported** and have been superseded by `agon`:

- `claudes-ai-buddies` → now part of **agon** (and better)
- `codex-ai-buddies` (the "codex evil twin") → now part of **agon** (and better)
- `evil-twin` → now part of **agon** (and better)

- Still using one of these? Do yourself a favor and switch to **[agon](https://github.com/KERNlang/agon)** — it's faster, cleaner, actively maintained, and rolls all of the above into one tool. Come check it out and give it a star.
